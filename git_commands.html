📖 Tổng Hợp Các Câu Lệnh Git Cơ Bản

Hướng dẫn tra cứu nhanh các lệnh Git thông dụng dành cho lập trình viên

🚀 Quy trình cơ bản đẩy dự án lên GitHub

  1. Khởi tạo kho lưu trữ cục bộ: git init
  2. Thêm tất cả các tệp vào khu vực chờ (Staging Area): git add .
  3. Lưu lại lịch sử thay đổi: git commit -m "Nội dung mô tả commit"
  4. Liên kết với kho từ xa (GitHub): git remote add origin https://github.com/<user>/<repo>.git
  5. Đẩy code lên nhánh chính: git push -u origin main

⚙️ 1. Khởi tạo & Cấu hình

git init

Khởi tạo một Git repository mới tại thư mục hiện hành.

git clone <url>

Sao chép một repository từ GitHub hoặc remote server về máy cục bộ.

git config --global user.name "Tên Của Bạn"

Cấu hình tên hiển thị cho các commit.

git config --global user.email "email@example.com"

Cấu hình email tài khoản GitHub.

📝 2. Quản lý Thay đổi & Commit

git status

Kiểm tra trạng thái các file (đã sửa đổi, đã đưa vào staging hay chưa theo dõi).

git add <tên_file> / git add .

Thêm file cụ thể hoặc tất cả thay đổi vào khu vực Staging Area.

git commit -m "Thông điệp commit"

Tạo một commit ghi lại các thay đổi đã stage.

git diff

Xem chi tiết các thay đổi so với commit gần nhất.

🌿 3. Làm việc với Nhánh (Branch)

git branch

Liệt kê tất cả các nhánh hiện có trong repo cục bộ.

git branch <tên_nhánh>

Tạo một nhánh mới.

git checkout -b <tên_nhánh> / git switch -c <tên_nhánh>

Tạo nhánh mới và chuyển sang làm việc trên nhánh đó ngay lập tức.

git merge <tên_nhánh>

Hợp nhất nội dung từ nhánh chỉ định vào nhánh hiện tại.

☁️ 4. Đồng bộ với Remote (GitHub)

git remote -v

Xem danh sách các remote URL đang kết nối.

git push origin <tên_nhánh>

Đẩy các commit từ nhánh cục bộ lên repository trên GitHub.

git pull origin <tên_nhánh>

Kéo và tự động hợp nhất các commit mới nhất từ GitHub về máy.

git fetch

Lấy dữ liệu mới nhất từ remote về nhưng chưa hợp nhất vào code hiện tại.

⏪ 5. Lịch sử & Hoàn tác

git log --oneline

Xem lịch sử các commit đã thực hiện theo dạng rút gọn.

git reset HEAD~1

Hủy bỏ commit gần nhất nhưng giữ lại các thay đổi trong file.

git stash / git stash pop

Tạm cất các thay đổi chưa commit để chuyển việc khác, sau đó lấy lại.
